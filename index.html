Política de Privacidad

Aplicación: COLOR CASCADE - CATCH COLOR (com.themostdumbgames.colorcascade)
Desarrollador: The Most Dumb Games
Última actualización: 18 de noviembre de 2026

The Most Dumb Games ofrece la aplicación móvil COLOR CASCADE - CATCH COLOR de forma gratuita con soporte publicitario. Esta Política de Privacidad explica de manera transparente qué datos se recopilan, cómo se utilizan, con quién se comparten y cómo se protegen al usar nuestra aplicación.

1. Datos que recopilamos directamente

COLOR CASCADE - CATCH COLOR no ofrece creación de cuentas, inicio de sesión ni compras dentro de la aplicación, y no recopila directamente datos personales identificables (como nombre, teléfono, contactos, ubicación precisa, cámara o micrófono).

Las puntuaciones máximas y preferencias del juego (como el idioma o el sonido) se guardan únicamente de manera local en el dispositivo del usuario.

2. Publicidad y servicios de terceros (Google AdMob)

La aplicación integra únicamente el SDK de Google AdMob (Google LLC) para mostrar anuncios. Al usar la aplicación, Google AdMob puede recopilar y procesar automáticamente ciertos datos del dispositivo:

  • ID de Publicidad de Android (AAID) y otros identificadores restablecibles del dispositivo, utilizados para mostrar anuncios, limitar su frecuencia y medir su rendimiento.
  • ID del Conjunto de Aplicaciones (App Set ID), utilizado exclusivamente para fines esenciales no publicitarios, como análisis técnico y prevención de fraudes. Este identificador nunca se usa para personalización o medición de anuncios ni se vincula con el ID de publicidad ni con datos personales.
  • Información técnica y de diagnóstico (modelo del dispositivo, versión de Android, idioma, dirección IP aproximada y registros de fallos o rendimiento).

Puedes consultar cómo Google gestiona los datos en sus servicios publicitarios en: https://policies.google.com/privacy.

3. Restricciones y prácticas de uso de datos

  • No vendemos datos personales ni sensibles de los usuarios a terceros.
  • La aplicación y el SDK integrado no recopilan ni vinculan identificadores persistentes del dispositivo (como IMEI, IMSI o número de serie de SIM) con identificadores restablecibles ni con datos personales o sensibles.

4. Seguridad de los datos

Toda transmisión de datos entre la aplicación y los servidores de Google AdMob se realiza de forma segura mediante cifrado moderno en tránsito (protocolo HTTPS).

5. Retención y eliminación de datos

No almacenamos cuentas ni datos personales en servidores propios de The Most Dumb Games.

  • Datos locales del juego: puedes eliminarlos de forma definitiva en cualquier momento borrando los datos de la aplicación desde los ajustes de tu teléfono o desinstalando el juego.
  • Preferencias de anuncios: puedes restablecer tu ID de Publicidad o inhabilitar la personalización de anuncios desde Configuración de Android > Google > Anuncios.

6. Privacidad de menores (+13)

COLOR CASCADE - CATCH COLOR está dirigida a un público general mayor de 13 años y no está diseñada para niños menores de 13 años. No recopilamos intencionadamente información personal de menores. Si eres padre, madre o tutor y crees que un menor nos ha proporcionado datos personales, contáctanos para atender tu solicitud de inmediato.

7. Usuarios en el EEE, Reino Unido y Suiza

Para usuarios ubicados en el Espacio Económico Europeo (EEE), el Reino Unido y Suiza, el tratamiento de datos vinculados a la publicidad se realiza conforme a las leyes de protección de datos aplicables (como el RGPD) y a los mecanismos de consentimiento y transferencia de datos vigentes.

8. Cambios a esta Política de Privacidad

Podemos actualizar esta política ocasionalmente para reflejar cambios técnicos o legales. Cualquier modificación se publicará en esta misma página actualizando la fecha superior.
